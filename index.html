Политика конфиденциальности — «DNS инструменты + Код контрагента»

Дата вступления в силу: 15 сентября 2026 г.

Расширение «DNS инструменты + Код контрагента» — внутренний инструмент для сотрудников DNS. Мы уважаем вашу конфиденциальность.

1. Какие данные мы собираем

Мы не собираем, не храним на серверах, не продаем и не передаем третьим лицам никакие персональные данные.

Расширение работает полностью локально в вашем браузере.

2. Локальное хранение

В chrome.storage.local на вашем устройстве хранятся только технические настройки:

  • extEnabled — включено/выключено расширение;
  • autoReloadEnabled — включено/выключено автообновление страниц sale.

На сайтах sale.dns-shop.ru в localStorage временно сохраняются выбранные вами фильтры (saleFilters) и URL (saleReloadUrl), чтобы восстановить их после автообновления страницы. Эти данные не покидают ваш браузер.

3. Сетевые запросы

Расширение обращается только к официальным доменам DNS для выполнения своих функций:

  • https://www.dns-shop.ru/* — поиск товаров, получение кодов;
  • https://*.sale.dns-shop.ru/* — страницы, на которых работает расширение;
  • https://restapi.dns-shop.ru/* — получение данных общей корзины по вашей явной команде.

Никакой аналитики, трекеров, рекламных SDK и отправки данных на сторонние серверы нет.

4. Разрешения браузера — зачем они нужны

  • clipboardWrite — копирование кодов товаров/контрагента в буфер обмена по вашей команде;
  • scripting — чтение данных корзины со страницы и восстановление фильтров;
  • storage — сохранение настроек вкл/выкл локально;
  • alarms, tabs — автообновление вкладок sale раз в 8 минут (можно отключить).

5. Передача данных третьим лицам

Отсутствует. Данные не передаются третьим лицам, не используются для рекламы и не продаются.

6. Дети

Расширение предназначено для сотрудников (внутренний корпоративный инструмент) и не ориентировано на детей.

7. Изменения политики

При изменении политики новая версия будет опубликована на этой странице с обновленной датой.

8. Контакты

По вопросам конфиденциальности: разработчик расширения (внутренний инструмент DNS). Обращайтесь через владельца публикации в Chrome Web Store.
