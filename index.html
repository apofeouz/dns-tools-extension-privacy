DNS инструменты + Код контрагента

Внутреннее расширение для сотрудников DNS · Chrome / Edge · Manifest V3 · v1.0.0

Массовый поиск товаров на DNS, копирование кодов из корзины и конфигуратора, копирование кода контрагента.

Возможности

  • Массовый поиск товаров на dns-shop.ru по кодам / артикулам / ссылкам
  • Копирование кодов товаров из корзины и конфигуратора
  • Копирование кода контрагента на *.sale.dns-shop.ru
  • Ссылки на каталог, информация о магазинах
  • Автообновление sale-страниц раз в 8 минут с сохранением фильтров (можно отключить)

Установка

Расширение распространяется через Chrome Web Store (внутренняя публикация, черновик).

Для разработки: chrome://extensions → Режим разработчика → Загрузить распакованное расширение.

Поддержка и конфиденциальность

Страница поддержки

Поддержка: через владельца публикации в Chrome Web Store.
Конфиденциальность: privacy.html — данные не собираем, всё хранится локально.
