Как сообщить о проблеме

Напишите владельцу публикации в Chrome Web Store, указав:

  1. Версию расширения (посмотреть: chrome://extensions)
  2. Версию Chrome / Edge
  3. Страницу, где возникла ошибка (корзина / sale / каталог)
  4. Скриншот консоли (F12 → Console), если есть

Частые вопросы

Расширение выключено (бейдж OFF)?
Нажмите на иконку расширения в тулбаре, чтобы включить.

Не работает автообновление sale?
Проверьте настройку autoReloadEnabled — она хранится локально в браузере.

Не копируется код?
Дайте странице полностью загрузиться, затем повторите. Разрешение clipboardWrite используется только по вашей команде.
